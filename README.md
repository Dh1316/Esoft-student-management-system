# Esoft Student Management System - C#
A simple console-based CRUD application developed for Esoft HND AI coursework.

Developed by: Dushan Pasinda | HND in AI @ Esoft Metro Campus

### Features
- Add new students with auto-generated ID
- View all students
- Search students by name (using LINQ)
- Delete students by ID
- Persistent storage using file handling (students.txt)

### Tech Stack
- C# .NET
- System.IO for File Handling
- List<T> Collections

### How to Run
1. Clone this repo
2. Open Program.cs in Visual Studio
3. Press Ctrl + F5

This project is part of my learning journey in C# for HND.
